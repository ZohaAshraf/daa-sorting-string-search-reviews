# DAA Assignment 3: Sorting and String Searching on Real Data

CS2009 Design and Analysis of Algorithms, Fall 2026, FAST-NUCES.

All algorithms are written from scratch in Python and run on the
Amazon Fine Food Reviews dataset (500K+ reviews).

## Parts
- Part 0: Data preparation
- Part 1: Heap sort and top-K
- Part 2: Counting sort, radix sort, bucket sort
- Part 3: Naive search, KMP, Rabin-Karp
- Part 4: "gluten free" pipeline

## How to run
Put `Reviews.csv` in the `data/` folder, then run `python part0_prepare.py` first.
